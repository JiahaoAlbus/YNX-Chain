# Open Questions — YNX Trust Center

These are integration or release questions, not requests for secrets in chat.

1. Which canonical Gateway registry version will own `ynx-trust-center-v1`?
2. Will Governance own all review/reject routes, or will a distinct Trust authority own evidence and appeals?
3. Which canonical Data Fabric event schema/version will replace the candidate Trust event names?
4. What retention/deletion policy will legal and privacy review approve for evidence, appeals and audit hashes?
5. Which encryption-at-rest and remote backup custody standard will 30 Security/SRE accept beyond the current local SHA-256 consistency seals?
6. Which deployment environment will provide the first authoritative shared-Testnet endpoint?
7. Which healthy Android/iOS execution environment and signing class will be used for release evidence?
8. Which CI workflow and immutable artifact host will publish the Trust server/CLI bundle after local provenance gates pass?

Until resolved, corresponding states remain blocked or in progress rather than complete.
