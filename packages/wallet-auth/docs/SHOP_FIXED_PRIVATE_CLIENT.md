# Fixed Shop Native client adapter

The Node-only `original-shop-private-client` subpath acquires only the original fixed Auth image through its existing pre-load admission gate. It captures both own Native acquire/recognizer references before zero-argument acquisition. There is no provider, URI, endpoint, key, Root setter, raw-client injection or constructor API. The returned SDK owner is resource custody; identity calls the captured actual Native recognizer on the retained original receiver. Every non-cleanup operation additionally uses actual Native current. JavaScript identity and a caller current callback never create Source/session/permission.

Native acquisition and asynchronous read envelopes adopt a nonnull owner before interpreting error presence. Error presence is independent of false, zero, null or undefined. Native methods and the cleanup-only `readOriginalCustodyDATA()` are captured from the same original receiver before publication. SDK class/prototype/instance slots are sealed during trusted construction. Cleanup does not reload the image or reacquire admission.

`readOriginalShopNativeInvoiceRequestDATA(order,current)` passes the SAME current function with its actual AbortSignal to `readOriginalShopInvoiceTransport`. It verifies original status 200, `GET`, `/v5/shop/source/shop.order/invoice-intents/` plus the unchanged original token (no URL encoding), exact `application/json` and a nonempty original body up to 1 MiB. Scope DATA is bounded at the supplier's 32768 bytes. Buffers are copied with typed-array intrinsics; shared/resizable views, getters, proxies, invalid UTF-8 and a retained BOM are rejected. Generic bounded JSON rejects duplicate/prototype keys, unsafe integer conversion, trailing data and excessive depth/count. It accepts ordinary JSON whitespace/order and never compares canonicalJSON with raw HTTP bytes. It returns **unknown DATA**, not an invoice approval. The original P06 `nativeInvoiceProductIntentData` alone checks the existing business fields. No older OPEN protocol wire is used.

The same order retains its original Promise; a fresh query guard revalidates successful DATA without changing the original Native call context. it cannot produce a second GET, including after UNKNOWN. Up to 64 original order records retain their bounded original transport copies privately for first-cause custody. A closed or failed Source cannot turn a previously successful cache into fresh authority. Cancellation and late replies retain the same client/response; an active call blocks parent close.

Response cleanup precedes client cleanup. Only the captured Native `readOriginalCustodyDATA()` exact `{selected,unknown,physicalDone}` witness clears physical debt. No exception property is trusted. A first false/zero error can remain rejected while the true witness says physical cleanup completed. Preselection PENDING may explicitly progress the same response; selected UNKNOWN reuses the same selected Promise and never starts another release/GET. The client stays retained until its own true witness completes. Source/Session/proof/transport cleanup still belongs to Native. Missing/malformed witness remains closed with debt retained.

The original P07 handler emits `json.Marshal(data)` and writes those bytes; the wrapper imposes no canonical ordering/newline requirement. PUBLIC model tests include an exact test-only copy of the original P06 validator, not a second production business codec. Actual Root rows, genuine ShopSession importer/current, matching whole Native image and normal service qualification remain independent supplied dependencies. Model success and package/import success do not establish any of them.

The frozen custody getter supplier has a legacy V2 proof-consumer branch. Reusing its cleanup-only observation ABI is not a normal V4 PQ GET qualification. This adapter has no V2 signer/introspection/P256 fallback and cannot supply the missing normal V4 producer or a matching qualified image.
