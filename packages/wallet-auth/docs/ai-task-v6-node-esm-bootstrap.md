This successor changes only the Node bootstrap and its custody/debt. Request35,
response16, E5 framing,14 operations and agent15 scope remain unchanged. It is
not an Expo/RN/Hermes/JNI/JSI implementation, Native/Root/Source admission or a
business approval. No key, network service, Root row or signer is created.

The fixed private helper src/original-ai-task-action-v6-node-loader-private.js
has no TLA and takes no URI/provider/callback arguments. Auth synchronously
requires only this evidence helper, never the body. The Native actual tagged
Source owner (not a Wallet Main owner) owns its independent OriginalClientRoot,
verifies signed scope.imagePins.privateModule and compiled_private_kernel path/
bytes/SHA, and supplies exact {version:1,clientURI,assertCurrent,acceptCompleted}.
Helper port current is Root current; it must NOT require body ready. Actual
body loading is real Node await import of the canonical file URI, without query,
fragment, foreign host or normalization aliases. A thenable substitution result
must be an actual module namespace. Port and late namespace are retained before
late current/retirement checks. Only this actual import path writes the owner-
keyed WeakMap evidence. isOriginalAITaskActionClientV6ModuleImportDATA(owner,ns)
and consumeOriginalAITaskActionClientV6ModuleImportDATA(owner,ns) exist only in
the synchronous acceptCompleted window. Consume is one-shot. Native first holds
SAME namespace, then checks is AND consumes, rechecks Root, calls the unique body
factory. No ordinary {current:true}, caller namespace or hash can create evidence.
One import attempt per owner; different legitimate owners support account switch.
Retire invalidates acceptance immediately; join waits actual import settlement.

1. Existing fixed-image pre-load guard; synchronous Native acquire explicit

An acquisition/bootstrap failure preserves actual .partial plus .bootstrap
cleanup controller and explicit .errorPresent/.cleanupOnly. It never reacquires
or reimports. Falsy original cause is retained. If acceptance consumed but its
late Root fence fails, cleanup captures the already-existing same ready flight
without triggering a body factory. Retire invalidates helper and logical Native
owner; joining import + ready precedes Native Source join/close. Pending join
blocks close. The same owner can finish later drain, while first cleanup cause
remains sticky even when later join errors differ. Unknown close is retained,
not replayed as a new close/effect. Successful client close also retires and joins
its import controller before the original proof/review/lookup child and Source
cleanup. Original packet bytes/AbortSignal/UNKNOWN/business lifecycle are unchanged.
