# Original Native Pay response observation DATA

`inspectPQNativePayResponseDATA(snapshot,{member,originals},target,response)` is a Node-only synchronous parser/math helper. It reuses `preparePQNativeActionTransportData` and the original action codec; no Core transport, signature primitive, action wire, Source, signer, network client or transaction state machine is added. The supplied snapshot must be the same original selected/reviewed SDK snapshot; actual provenance and use-time current remain Main/Auth responsibilities. A newly fetched account nonce is not a reason to rewrite or replay the original signed action.

Only invoice_terms/invoice_settle/invoice_refund, single Member N1/index0/empty paths, and empty classic originals are accepted. Target for terms is exact `{intentId}` with the original server npi_48hex. Settlement/refund target is exact `{}`. Merchant/invoiceId derive solely from the decoded signed action: terms/refund merchant is action.owner; settlement merchant is action.payload.merchant. No caller URL, owner, nonce, amount or alternate path is accepted.

Actual routes are POST /v5/pay/invoice-intents/{intentId}/merchant-member, POST /v5/pay/invoices/{merchant}/{invoiceId}/settlements and /refunds. They are not /transactions/pq/actions/broadcast. Actual packet is exact method/requestPath/status/contentType/cacheControl/body:Uint8Array. Body is bounded2MiB, owned through typed-array intrinsics before existing mathematics run; Proxy/getter/SAB/detached inputs fail without executing callbacks. Original Main must persist its complete real response packet BEFORE invoking this helper or any later current/lock/completion/cleanup fence. A parser failure cannot justify dropping that raw response or clearing UNKNOWN.

Terms bind intent/originalOperation, merchant, original message SHA, all twelve Core terms fields using the existing payload encoder, immutable request network/merchant/recipient/asset/unit/amount and any provided original hashes. NativePayOperation binds both full original Member/envelope base64 bytes and their distinct original SHA256 hashes, kind/owner/merchant/invoice. Optional service nested invoice/observation/effect and product domainData remain owned original JSON spans. Their numeric tokens are never JS Number, preserving all u64/floats exactly. They are explicitly untrusted observations; this module never verifies Core H/H+1 effects/history or a Pay proof Source.

The parser accepts standard Go JSON field order/whitespace/escaping, rejects duplicates/prototype keys/trailing documents/extra root fields/types/invalid UTF8 and bounds, and requires canonical decimal strings wherever Core terms/network fields require them. Nested arbitrary effect/observation object fields are preserved as raw bytes, not interpreted as an independently authenticated schema. No Core observation/effect struct was guessed. Error statuses400/409/413/415/503 accept exact `{code,error}` with the actual NATIVE_ error code shape and remain error-only observations. They are not proof of no execution.
