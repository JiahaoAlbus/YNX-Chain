This successor adds private portable implementation modules. It does not publish a new mobile Source factory or claim that the original full V6 Client is operational on Hermes. The normal Node Client remains separate; its request35/response16/E5/14ops and mandatory independent agent registration are unchanged.

`original-ai-task-action-v6-mobile-data.mjs` imports only the existing locked production dependency `@noble/hashes/sha2.js` (2.2.0) for SHA-256. It copies actual Uint8Array bytes through captured TypedArray intrinsics and native set, rejects other typed arrays, proxies, shared/detached buffers, and never accesses own buffer, iterator or tag getters. Existing fixed body/member/source-original caps are retained. Body digest and byte count cover raw bytes, not UTF8 or JSON re-encoding. Known empty/abc SHA-256 vectors and a binary value are checked independently. DATA is not signature verification.

The finite agent metadata helper consumes canonical primitive JSON strings with the already frozen exact15 public expectation and exact5 expected network/owner/source/instance/resource selector. It checks canonical representation, shape, epoch and historical/profile windows without accepting a JS registration object. This is not a second registration wire, original signed-frame codec or protected record format. Auth must still independently verify the actual protected original digest, registration/revocation, key selection, scope/current and Root. `registrationVerified`, `signatureVerified`, SourceAdmission and NativeAdmission remain false.

`original-ai-task-action-v6-mobile-custody.mjs` is a resource controller, not Source/Native qualification. It retains SAME actual owner/partial before falsy error inspection, registers pending work before calling fixed foreign Native functions, blocks reentrant disposal, retains late owners through exit, and joins/closes review/proof/outcome/lookup children before Source. Its private callback is only an internal fixed Native invocation seam, not a public injected Source/provider. Cleanup deliberately does not reacquire Root/current or turn an expired Source into authority.
