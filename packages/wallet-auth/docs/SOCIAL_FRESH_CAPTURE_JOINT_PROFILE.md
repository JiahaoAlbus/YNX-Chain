# Same-capture joint-profile preparation

Existing Auth first captures LoadSourceAuthority / retainPreparedOrigin then reads a static protected profile. The verifier correctly requires the full signed current-history envelope SHA and independent issuer/anchor epochs to match that fresh capture. A persistent profile for capture A cannot be used for capture B with a new random nonce; do not freeze the nonce, substitute Records as a counter or reconstruct a parent from Root JSON.

The normal order is one actual retained prepared Source capture -> independently registered finite issuer resource -> unchanged canonical body16 for SAME capture -> original protected record-issuer and record-anchor Source signatures -> existing retain/verify profile -> same-owner request qualification/current. Body expiry is bounded by history expiry, actual independent captured-owner deadline and both matching capability windows. There is no new signed field, domain, algorithm, provider, endpoint or operational key here.

body.go exposes PrepareBodyDATA and InspectBodyOriginalDATA. They are executable reference DATA consistency helpers, not native or protected issuer factories. The exact existing Go struct order/JSON HTML escaping and uint64 numeric wire encoding are preserved. No JS Number handles epochs or Source generations; contract.d.mts describes lossless collector metadata only, not another signed encoding. Signal Classic33 and MLDSA87 2592-byte public key are independent full registered originals, never E5/N1/Wallet asset key conversions.

The four raw inputs are full actual history envelope, issuer credential, anchor credential and registration originals. This helper hashes actual history bytes and checks body/context/window consistency; it does not parse/verify their signatures or prove their owner/lifetime. Auth must independently hold and recheck the original prepared Source's pointer, signed issuer/anchor credentials, registration/current/revoke and physical debts before/after issuing and qualifying. Do not treat helper PlanDATA, public metadata or matching hashes as SourceGrant. Plan admission flags are always false.

The existing profile policy10 role pair and expected17 remain unchanged. policy.network ASCII128 and expected.networkId hex64 are not asserted equal or mapped from fixtures. Auth must supply any genuine registered cross-domain mapping. Body Identity/Device, Signal/PQ and DEVICE/session binding also require genuine registered owner validation; byte agreement alone is DATA.

Default issuer resources remain the actual Auth empty compiled registration until a separately authorized protected issuer resource is supplied. SDK does not call issuance/current loaders, open private keys, sign, install or activate. Concrete protected issuer factory names and private same-capture loan methods must match Auth's actual mother implementation; this module supplies no invented opaque factory or callback seam. Existing Source role artifact helper is only an unverified public signature artifact projection, not an issuer authorization loan.

New controls cover old static-profile cross-capture rejection followed by new same-capture preparation, non-equivalent epochs/generations, actual byte changes, session/device/fullpair changes, exact windows, absent issuer and canonical BOM/duplicate/unknown refusals. These are PUBLIC DATA fixtures, not actual signed profiles. Normal CI runs Go1.25.13 new9 and strict5 only. Old stdio/ACK/Source math/Native suites are not rerun.
