It supersedes the private candidate's wire labels, not its protected Source/SQL/Node semantics. `PROTOCOL_PROPOSAL.json` was read and SHA256 matched `bba45f032ddc7a62611e1626f3250edd5968abbad6b271063eca0ce975ba62e3` (6011 bytes). ## Bytes, exact fields and method

Request, signed typed payload and outer response are strict canonical UTF8 JSON. Keys have schema ASCII names, lexical order, no whitespace/BOM/unknown/duplicate/escaped alternate representations; strings have strict UTF8 with no unpaired surrogate, no Unicode normalization. Raw byte fields in the request and outer carrier use canonical unpadded base64url; roundtrip rejects padding, whitespace and tail-bit aliases. This final public grammar uses lowerCamel field names, version string `1`, and lowercase hex64 for the exact32 network bytes in payload `chainID`. Original protocol-owner adapters must use this SDK codec; no private Go struct-order JSON, old candidate version or alternate base64 carrier is a second accepted wire.

Signed payload has exactly the original25 logical fields in the machine contract. Purpose/domain is uniquely `YNX-OPEN/TASK-AUTHORITY-RESPONSE/1`. It does not reuse E21 BOUND-GRANT or E3 GRANT-EFFECT domains; those original payload/wire byte strings remain unchanged and have their own independent dual Binds. No binary E25 rewrite or duplicated E21 codec is introduced. Node reuses decodeBoundGrant/decodeGrantEffect/encodeBoundGrant for actual inner proof and step validation; Go reuses its original codecs and private same-package step/ref/bind validators. Structural JSON step checks are not an authority or an alternate business wire.

Transport explicitly includes actual `method:'POST'` for both effect and query, plus action/path/service/origin/actual MIME/status. Method is signed and never inferred from action or path. Actual registered path/service/origin/MIME/status must independently match the caller's original transport expected. There is no route/default/origin-based trust installer. Status200/409 is DATA;409 requires UNKNOWN but cannot alone prove it.

ResponseIssuer is a complete exact5 `{realm,tenant,kind,id,rev}`. Its independent registered subject is `expected.issuer.principal`, also complete exact5. Ref fields are strict nonempty UTF8<=256bytes, rev canonical U64; `encodeTaskAuthorityFullRefDATA` supplies exact RefE5 bytes for comparison/interop. No missing realm/tenant/kind/rev/epoch is filled from ID, URL, legacy ID or another revision. IssuerEpoch, PolicyRevision, Height, network and issuer expiry are independent explicit expected values. Only service/organization response issuer roles are structurally supported. Cross-organization issuer refs are not rejected merely because their tenant differs from top-level tenant: the exact relationship must match independently registered/current Root pins. Actual inner grant refs keep their original codec's scoped legacy compatibility semantics; this module does not broaden them or migrate IDs.

CurrentTaskRevision and CurrentGeneration bind the exact protected request narrowing and independent current values; they are distinct from immutable original grant task revision/generation. Query GrantRef current revision may advance from signed grant revision, as the original Auth call permits; effect must retain exact original grant revision. A cold query may have no raw original effect input, but it must retain the exact original Node operation ID selected for that original query. No local EffectRef, step, nonce, request ID, changed body or new generation can become a new original operation.

## Original actual byte relationships

Payload binds all four original grant/holder payload/wire byte strings separately, complete original GrantStepBinding and request body, complete request carrier (including nonce/current narrowing), actual Node operation/state and original service response bytes. Envelope originalBody is the exact original Node response body; it is not opaqueOriginal. There is no signature self-reference: wholeServiceResponseBinding excludes the outer proof.

`opaqueOriginal` is the original STRING and only its exact strict UTF8 bytes are dual-hashed. It is never parsed as a resource body. `expected.opaqueOriginal`, operation/state and resource facts must come from the original Node/Source result callee which actually correlates the same response; these DATA arguments cannot attest their own provenance. This module preserves/compares the actual byte relationships and does not introduce a competing parser for private Node service JSON.

COMMITTED requires exact original resource operation, remoteRef, authScope, Source ref/rev/field mask/label/Bind and ResponseBinding. The expected actual ResponseOriginal and SourceBytes are separately captured and dual-hashed; selected Source resource/fields/label must match the original signed grant step. Resource.AuthScope retains the original string `egress-only-read-fence`; no account/wallet/asset approval is inferred. FAILED and UNKNOWN require resource:null and cannot return stale resource bodies as verified result. Ordinary read DATA does not authorize disclosure or VAULT egress; current Catalog/policy/resource authority must independently enforce it.

## Bounds and pre/post signing responsibility

Original request/body/proof components are independently bounded to1MiB; signed payload is<=65536. Exact final serialized response is<=the independently selected actual registered operation max AND<=1048576, including both base64 expansions, actual proof bytes, purpose/keys/JSON overhead. Node encode/decode require a second `maxResponseBytes` argument; Go requires the equivalent int. Missing/zero/noninteger/over-global cap is rejected. Binding assertion requires `expected.maxResponseBytes` / Go MaxResponseBytes. It is not encoded into or taken from the response itself. The original request transport must still enforce its actual registered request max before LINK dispatch; this DATA constructor does not supply that profile qualification.

No truncation, budget change or silent max expansion occurs. Producers must retain actual original operation/state/body/signature before attempting final serialization; a post-sign over-limit failure must preserve that signed partial and reconcile via the authorized original query, never re-sign/replay UNKNOWN. This DATA codec returns BOUNDS and performs no signer call, retry, dispatch, quota release or state transition. Caller/issuer already owns the original signed partial and must keep it under its original durable custody.

Node captures exact enumerable own DATA and typed bytes before processing using intrinsic typed-array buffer/length and native set, rejecting Proxy/SAB/detached/getters while ignoring hostile typed iterators/own buffer getters. Decoder output byte arrays are independent owned copies; arrays are caller-owned DATA rather than immutable capabilities. Go uses bounded typed values, strict JSON/canonical reencoding and clones returned originals; normal Go caller synchronization/data-race rules apply. Neither implementation has filesystem/network/Source/signing IO in production.

## Normal API and independent gates

Node API: encodeTaskAuthorityFullRefDATA; encode/decodeTaskAuthorityRequestDATA; encode/decodeTaskAuthorityResponsePayloadDATA; encode/decodeTaskAuthorityWholeResponseDATA; assertTaskAuthorityWholeResponseBindingDATA. Go has corresponding PascalCase functions in the existing OPEN package. Public Node-only export/subpath/version/normal package/CI remain parent-owned and are not written here.

Normal Auth producer obtains the actual protected caller/current Source, exact Node call/result and independently registered response issuer; constructs typed payload with this SDK; has the ORIGINAL protected Core custodian sign the exact canonical payload using the unique purpose and original N1/index0/empty-path complete ML-DSA-87 AND SLH-DSA-SHA2-256f; then serializes outer with this SDK and actual registered cap. No signer or Root registration is exported by this module.

Normal consumer independently selects original request/call/actual transport and current registered issuer; decodes this grammar, validates DATA relationships using assertion, and invokes ORIGINAL Core full-AND verification over exact payload bytes, independently pinned full subject/epoch/policy/network/height/purpose/service/authority/public keys. Original caller/registered-server/native LINK and Source current pre/post fences remain required, with authoritative time/expiry/replay ownership. Proof-embedded keys do not register themselves. An outbound client handle, received headers, JSON context, decoded result or DATA flag is not an inbound protected server Source or Principal.

Successful DATA outputs expose `dataOnly:true,signatureVerified:false,SourceAdmission:false,NativeAdmission:false,operationVerified:false`; payload state is declared state, not verified business truth. The raw typed-payload parser is a shape decoder only; its fields carry no authority. Actual Root/Profile registration, issuer keys/current, Source, Core signature verification, normal tools, model calls and deployment are not performed here.
