# Isolated Chain crypto v2 candidate

This nested module is inactive and is not imported by the root runtime. Run `cd internal/chaincrypto && go test -race ./...`. CIRCL v1.6.5 is locked by nested go.sum. Public vectors contain ephemeral synthetic signatures; no private key was serialized. Existing native SHA256 and Ethereum Keccak verification are unchanged. The candidate account envelope currently covers native-style SHA256 only; an Ethereum Keccak adapter is NOT implemented.

The first batch implements real secp256k1 AND ML-DSA-87 verification, Ed25519 AND ML-DSA-87 same-vote quorum verification, bounded canonical encoding/strict decoding, four policy states, opaque actual-dual-proof migration, and exact immutable authorized request readback. KeyManager is an interface only: durable platform key storage, atomic anti-double-sign signing, full Comet adapters, real Wallet backup/recovery, and committed nonce/state updates are remaining implementation work. The normal recovery path here still requires both existing keys and new PQ possession; loss-of-key prior recovery policy is not implemented. No claim is made that C01–C16 or X01–X04 are complete.

H_TX/H_CONS are unset. activationApproved=false, activated=false. No root module, genesis, chain state, consensus runtime, production key or Host was modified. Linux amd64 and Darwin arm64 builds compile the module; only Darwin tests executed. The local benchmark is one synthetic Apple M4 sample and is not node capacity evidence. Original parser/setup FAIL and subsequent repair remain in checks-receipt.json and original tool outputs.

The atomic-policy-state successor adds immutable migration capabilities tied to the whole network/policy/revision/nonce/activation-height/committed-height snapshot. Its concrete memory ledger consumes the nonce and changes policy in one lock; 16 concurrent copies of one actual dual-verified capability can commit only once. Cancellation after real verification and while waiting for the ledger lock, stale context, alias mutation and height boundaries are covered by targeted race tests. This is an isolated memory transaction implementation, not a durable chain-state or signer adapter. Persisted state authentication, durable atomic commit, actual Comet sign-byte adaptation, anti-double-sign key storage and recovery remain open. No experiment activation schedule is installed in the live chain.
