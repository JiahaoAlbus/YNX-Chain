Backup/restore retain it; rollback to formats lacking this protection is rejected. Old readers reject schema15 rather than dropping the guard.

It never treats identity as private authority. Missing Browser identity offers an explicit /sso/start link and keeps the original private approval available. A changed association requires an explicit new private approval; no old pending order is replayed automatically.
