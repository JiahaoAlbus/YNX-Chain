## Current verification

- `go test ./internal/economics ./cmd/ynx-economics-sim` — pass.
- `go run ./cmd/ynx-economics-sim -input economics/examples/medium-usage.json` — pass; five reconciled annual records.
- `go test ./...` initially exposed missing generated Solidity artifacts in three existing tests. After `npm run hardhat:build`, `go test ./internal/bftgateway ./internal/consensus` passed. This is a build prerequisite, not evidence that all final tokenomics requirements are complete.
- `make asset-primitives-check` covers local/race tests for the primitive library, v11 consensus integration, Gateway contract, schemas, and JavaScript SDK. No installed, staging, or public result is inferred from this local gate.
- `make bft-evm-access-list-transfer-check` covers chain-bound EIP-2930 type-0x01 decoding, empty-access-list enforcement, sender recovery, zero-based nonce, exact 21000-gas fee accounting, committed receipt audit binding, JSON-RPC type/accessList/yParity mapping, dual transaction identity, replay rejection, and fail-closed non-empty-access-list, calldata and contract-creation boundaries.
- `make bft-evm-dynamic-fee-transfer-check` covers chain-bound EIP-1559 type-0x02 decoding, zero-base-fee compatibility semantics, priority/max fee relation, maximum-fee affordability, exact effective fee debit, sender recovery, replay and wrong-chain rejection, audited receipts, type-0x2 JSON-RPC mapping and fail-closed access-list/calldata/creation/unsupported-type boundaries.
- `make account-abstraction-check` covers owner/session signature validation, sponsored batch execution, budget/lot/supply reconciliation, replay atomicity, migration, Gateway committed evidence, Bundler nonce signing/evidence verification, and access denial.
- `make solvency-check` covers exact native-liability aggregation, supply reconciliation, deterministic Merkle inclusion/tamper rejection, truthful external-reserve unavailability, and ABCI/Gateway proof agreement under normal and race execution.
- `make safety-module-candidate-check` covers insurance-first loss allocation, deterministic capped proportional slashing, cooldown eligibility, residual shortfall, recursive-restaking rejection, race execution, and a reproducible non-activated stress scenario.
- `make yusd-sandbox-check` — pass; race-enabled lifecycle, outage, pause, persistence, reconciliation, tamper, auth, and HTTP boundary coverage.
- `make liquid-staking-candidate-check` — pass; race-enabled model tests plus reproducible reward/slash/queue/pause/depeg scenario.
