# YNX Search Blockers

Updated: 2026-07-29T02:49:16Z

These dependencies do not block autonomous Search implementation work. They block
only the corresponding integration or release claim.

  verification and Product Session semantics.

- Resume condition: exact accepted registry and Gateway completion contract.

## EXT-PROVIDER

- Owner: operator
- Missing: approved production source inventory and selected official external
  Search provider agreement/credential.
- Prepared: provider-neutral adapter is the next autonomous slice; credentials
  must remain outside chat and Git.
- Why external: provider selection, commercial agreement and credential issuance
  cannot be manufactured by the Search repository.
- Minimum input after local adapter passes: provider identifier, official API
  base, credential reference, quota, retention terms and approved environments.
