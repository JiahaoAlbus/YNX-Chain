# Pay ecosystem release candidate notes — 2026-07-19

This candidate replaces product-local Wallet verification with the immutable
central Wallet protocol, introduces Wallet/Gateway merchant roles and adds the
independent YNX Card product and provider-neutral service. It also adds iOS
Simulator CI, exact server assertion contracts, review-only AI approvals,
persistent replay protection and current Android release artifacts.

This is not a deployed release. Central registry/proxy acceptance, staging,
fresh authoritative Testnet payment, current native install/visual matrices and
hosted signed artifacts remain mandatory before release completion.
