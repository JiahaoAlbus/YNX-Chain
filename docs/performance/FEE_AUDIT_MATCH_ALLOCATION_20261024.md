# 手续费历史审计比较的临时分配

节点实测 Commit 主要耗时在状态校验；旧四节点已验证报告中，候选侧均值约 41.834 ms，其中语义校验 13.477 ms、AppHash 24.781 ms。这里仅减少语义校验中每条手续费审计哈希的临时 hex 字符串，不将它称为最大瓶颈，也不推断网络收益。

每条历史仍按完整原 V1 字节合同重算 SHA-256。创建事件时仍返回原小写 hex 字符串；校验时将相同 digest 编码到 64 字节栈缓冲并作严格字符串相等比较。大小写、长度、非法字符、字段变化的拒绝语义保持。长字段仍按原逻辑扩容，不引入记录尺寸限制或缓存信任。

这是同二进制、固定历史的审计比较测量，非两个完整应用版本的吞吐对比。样本按路径分组，耗时有波动，不据此声称稳定加速；零堆分配仅限这段比较与本固定历史，不包含完整校验的索引、AppHash 或超长字段。

128 组原 formatter oracle 覆盖 NUL/Unicode/超长字段、整型边界、时间和时区，并检查匹配与字段变化。新增反例覆盖每个 digest 字符损坏、空值、截断、扩展、大小写及金额变化。完整 consensus 与 ABCI 套件通过，包含混合手续费顺序、签名/nonce/重放、提交失败和异常退出恢复；相关聚焦 race 通过。沿用原 make consensus-abci-check 自动执行，无新增重压测。
