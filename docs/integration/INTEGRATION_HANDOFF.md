Social owns profile, privacy, contact, group, feed and Social presentation
semantics. It consumes Wallet identity, Chat cryptography, Square posts, Pay
settlement, Trust cases, Cloud objects, Search indexing and Data Fabric events.
Those authorities must not be duplicated inside Social.

The current branch locally verifies device-bound authorization, strict product
bindings, replay and tamper rejection, session rotation, contacts, groups,
messages, receipts, reports, appeals, AI preview approval, local export/delete
and a 12-language native bundle. It does not prove shared-Testnet acceptance,
device installation, production signing, hosted downloads or public release.

Central acceptance requires exact Wallet introspection and revoke vectors,
canonical event registration, coordinated Chat/Square erasure, Pay/Trust/Cloud/
Search flows, Security review and retained Explorer/Monitor evidence.
