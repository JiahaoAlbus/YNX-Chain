BEFORE YOU START

Know what the workspace does.

Is this a production exchange?

No. This is a Testnet venue, not an exchange listing or mainnet custody service. YNXT is a test asset; YUSD_TEST is venue-only test credit. Public execution may remain disabled until custody and permission evidence is verified.

Do I need a wallet to browse?

No. Public views and previews remain separate from wallet approval, private account access, signatures and transactions. Never enter a private key or recovery phrase into this page.

How does this relate to Finance and Quant?

Exchange is a workspace in the YNX Finance category. Existing Finance and Quant research capabilities remain separate working surfaces; this introduction does not create a new financial service.
