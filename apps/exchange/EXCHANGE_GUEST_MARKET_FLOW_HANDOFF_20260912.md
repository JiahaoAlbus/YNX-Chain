## Runtime behavior

- `GET /api/v1/market-data/snapshot` returns one durable snapshot using schema
  `exchange-public-market-v1`: revision, market, order book, latest 1,000 actual
  matches and source metadata. The service is mounted under `/api`; its internal
  handler path is `/v1/market-data/snapshot`.
- `/api/v1/market-data/stream` supplies snapshots/reconciliations and bounded
  heartbeats. The write deadline is refreshed for each SSE write; slow writes
  remain bounded. REST order-book/trade routes remain available.
- Guest requests use same-origin public GETs, independent of Wallet or private
  Product Session. HTML fallback, malformed data and unavailable sources are
  failures, never a fabricated empty order book.
- Disconnect keeps the last valid snapshot explicitly labelled stale. Retry,
  online recovery and restored browser pages obtain a fresh snapshot before a
  fresh stream. Old HTTP responses and old stream callbacks cannot overwrite a
  newer connection. Without EventSource, a five-second read-only poll is used.
- Guest projections omit account, reservation, authorization, participant and
  private order-link/fee fields; authenticated account snapshots are unchanged.
  Full source digests remain available in the tape. Large displayed notionals use
  integer micro-units without floating-point multiplication.
- The chart is still a latest-60 matched-price line, **not OHLC candles**. Multiple
  candle periods remain an explicit subsequent functional gap.
