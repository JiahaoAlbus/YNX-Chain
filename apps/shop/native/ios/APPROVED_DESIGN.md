# Approved Shop native design

The buyer desktop/mobile and Agent workspace use the user's `ynx-shop.kui.fig`
(SHA256 `e05b094a394839fec55f33919faa68809de3cbf4b2c295d7abdecc97d780dd47`).
The complete local canvas was decoded before implementation: 59 product frames,
77 variables and both light/dark modes. `ShopTheme.swift` and the `KUI.*` color
assets retain the design's actual values. The original input is preserved outside
the repository. No remote Figma file key or screenshot comparison is claimed.

The two editorial PNGs are original design assets, distinct from live product
media. Desktop: 1040×472, SHA256
`01441bf7cbf7994bd3aacdf8502c65505c565ca7630db696f27f1afce1e33a89`.
Mobile: 740×280, SHA256
`b281a6393786e859019ce8c85ad7535d5310ae35b2e58e7c59ee5e9ac839b4cc`.
Product images, variants, inventory, prices and orders continue to come from the
original API. Missing tax, logistics, authenticated account or payment services
remain unavailable. MiSans uses native font fallback when absent; exact installed
font fidelity and rendered layout still require matching-candidate visual QA.

A comparison starts with disclosure of selected public catalog data. Explicit
consent creates a draft job; generating and accepting its draft are separate
user actions. Processing units are not money or a spending grant. A durable
original request is stored before dispatch. Lost acknowledgements use original
lookup/read routes, never replacement creation or generation. Cancellation and
late completion preserve the original operation and its terminal state. Applying
a draft creates no order, cart mutation or payment.

`AgentComparisonChecks.swift` and `AgentModelChecks.swift` exercise frozen
requests, cold recovery, lost acknowledgements, disclosure/identity fencing,
cancellation races, storage refusal and exact integer amount display. Controlled
HTTP/authority fixtures grant no real Wallet, provider, Source or funds authority.
The original native CI builds both Apple targets and runs these checks. Source,
package, installed visual acceptance, real business acceptance and publication
remain separate results. Existing frozen candidates are never modified.
