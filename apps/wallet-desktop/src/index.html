Read a contract

Query the existing YNX Testnet contract runtime. This does not sign, submit a transaction or grant permissions.

The current runtime uses hex calldata. A listed method with no arguments can fill its selector. For a method with arguments, supply its complete encoded calldata. Legacy mode accepts a pure/view function name or calldata. There is no automatic fallback between runtimes.



Supported pinned artifacts and a bounded static-call interpreter only. This is not general Ethereum execution, contract deployment or a contract write. A read result is not consensus finality or a transfer confirmation.
