Current route selection also binds the official `/api/v1/epoch/current` response. The source contract's absolute epoch ID is `total_elapsed_epochs`; `current_epoch_start + epoch_length` supplies the expiry. The directory must match that epoch, have a cache timestamp within one epoch duration, and leave at least five minutes before epoch end. Official `refreshed_at` is the minimum timestamp of rewarded-set, node-status and description caches; it is not a newly issued role timestamp, so a two-minute age bound is not valid for this API. Plans require that selection proof, recheck it at startup/status and expire one minute before the epoch ends. A 15-minute metadata age alone was inadequate. Recorded requests to the earlier active exits finished before the epoch transition, so their HTTP timeouts are not attributed to that later transition.

`run_profile_operation.py` and Native share an exclusive profile lease. The runner handles termination through official SIGINT, confirms exit and key/config binding, and hashes client/recipient addresses and anonymous sender tags in captured runtime logs. Scoped diagnostics record actual consumed memory settings, DOMAIN/port and byte counts, SURBs generated/queued, ACK events and reply decryption/response sizes. None of those events replaces normal TLS, response content or installed-window acceptance.
