## 范围与用途

本草稿说明 YNX 测试网（链 ID 6423）浏览器扩展的数据处理。官网/PWA、RPC 基础设施、浏览器商店和第三方 DApp 可能另有政策，发布前须确认运营方并提供准确链接。扩展管理本地 YNX 账户，不通过 MetaMask 登录。

账户数据用于创建或导入账户、本地保护密钥、连接您批准的网站、查看及签署请求、查询测试网信息和恢复结果不明确的交易。

私钥以密码加密的密文保存在当前浏览器配置中。密码仅用于本地派生加密密钥，扩展代码不会上传密码或原始私钥/恢复密钥；创建、导入和授权时会在内存中处理它们。恢复密钥可能显示给您用于离线备份。这是本地密码加密，不代表硬件绑定托管。

公开账户信息与批准的网站来源在本地保存。获准的 DApp 会收到公开账户地址，您批准的消息或类型化数据签名会返回该 DApp，用于认证或授权操作。DApp 可自行保存这些信息或发送到其服务端，请在批准前查看网站身份、请求和隐私政策。

钱包查询会向 `https://evm.ynxweb4.com` 发送账户地址、哈希及允许的请求参数。DApp 可在不触发账户连接或签名提示的情况下请求公开的只读 RPC 信息；交易则需要另行查看并输入密码授权。批准后的原始已签名交易会发送至该 RPC，并可能在测试网节点和区块浏览器中公开。RPC 会收到包括 IP 地址在内的常规连接信息。扩展使用 HTTPS 并在 RPC 请求中省略 Cookie，但这不代表服务器没有日志。

广播前，扩展会在本地保存原始已签名交易、账户、来源网站、RPC 来源、哈希与结果/证明，并按哈希保留历史。这些交易记录**不使用保险库密码加密**。已签名交易不是私钥，但可以被广播。保留它们是为了在回执丢失后避免误生成替代交易。

语言和公开连接设置保存在扩展页面的本地存储；待批准请求和防重放记录使用浏览器会话存储，并尽可能在完成后清理。本次审查的扩展未实现分析统计、广告标识、遥测上传或远程崩溃报告；不抓取普通网页全文、浏览历史、Cookie、书签、联系人或网页密码。请求网站的上下文及通过钱包 API 主动提供的数据，仅用于上述钱包功能。

## 控制与保留

您可以拒绝连接或签名请求，也可以撤销网站连接。这能停止后续授权，不能收回已经发出的地址、签名或交易。网络请求发出后取消界面操作，不能撤回广播。

“移除账户”删除当前配置中的加密保险库、公开提供者账户和网站权限，**不会删除交易恢复记录与历史**，目前也没有自动清理交易历史的期限。通过浏览器清除扩展数据或移除扩展可删除本地扩展记录；操作前请保存离线恢复密钥，并核实浏览器说明。PWA/网站数据、备份及外部副本需要另行处理。扩展不能保证从链上参与方、其他 DApp 或服务日志中删除数据。

本候选禁止隐私窗口运行。Firefox 网站权限按浏览器提供的容器标识隔离，每个容器须单独批准连接；加密钱包、当前账户和账户级交易恢复记录仍在扩展资料目录内共享，并非每个容器各有一个钱包。没有容器归属的旧 Firefox 权限须重新连接。容器标识只保留在本地，真实 Firefox 安装验证仍待完成。发布者须确认服务端保留与数据请求程序：**[SERVER_RETENTION_AND_DELETION_PROCESS]**、**[PRIVACY_REQUEST_PROCESS]**。扩展没有发布者代管恢复密钥或找回密码的服务。
