# YNX Wallet

商店文案草稿。发布者、支持联系方式和隐私政策地址待确认；含占位符时不可提交。清单名称仍为 `YNX Wallet`，版本为 `0.1.0`，尚未核验真实商店账户中的版本与标识是否可用。

## 简介

独立的 YNX 测试网钱包，用于经您批准的 DApp 连接、签名与受支持的转账。

## 单一用途

管理一个保存在当前浏览器中的 YNX 测试网账户，并由您明确授权兼容网站连接、请求签名或提交受支持的原生转账。

## 详细介绍

YNX Wallet 是 YNX 测试网（链 ID 6423）的独立浏览器钱包。您可以创建或导入账户，用本地钱包密码加密私钥，并逐项查看 DApp 发来的请求。钱包使用自己的 YNX 账户，不通过 MetaMask 登录。

**安装前请了解数据用途：** 扩展在当前浏览器配置中保存加密私钥、公开账户信息、已批准的网站来源和交易恢复记录；向 `https://evm.ynxweb4.com` 发送公开账户查询及经您批准的已签名交易，并向发起请求的 DApp 返回获准的账户信息和签名。签名消息可能用于身份认证或授权其他操作。扩展会为这些钱包功能处理 DApp 请求与响应内容。RPC 运营方会收到包括 IP 地址在内的常规连接信息。扩展不会上传本地钱包密码或原始私钥。安装前请阅读发布者确认后的隐私政策：**[PRIVACY_POLICY_HTTPS_URL — 待提供]**。

只连接您信任的网站。输入本地密码前，请检查请求网站、账户、完整消息或类型化数据。拒绝请求不会生成签名。网站可能保留已经获得的数据；撤销连接可以停止后续账户授权，但不能收回已经发出的签名或交易。

界面默认显示和复制带校验的 `ynx` 地址，标准以太坊兼容 API 返回同一账户对应的 `0x` 地址。扩展通过 EIP-6963 声明独立的 YNX 钱包提供者，支持 EIP-1193 账户连接、权限撤销、`personal_sign` 和受支持链上的 `eth_signTypedData_v4`。

转账受 RPC 实际能力限制，目前支持的范围是测试网正整额 YNXT 普通原生转账及其明确的手续费模型。缺少能力或无法验证时会停止操作。本预览不提供完整 EVM 合约执行、多网络、同时保存多个钱包账户、主网资产、兑换、质押、法币购买或挖矿。消息签名仍可能授权外部操作，不能因为标注测试网就批准陌生内容。

交易提交结果不明确时，扩展会保留原始已签名交易。您可以在账户保险库中查询状态，或重新检查并输入密码后明确重试相同交易。没有查到收据不代表交易被拒绝。移除账户不会删除交易恢复与历史记录，也不会删除链上或服务端数据。

请离线保存恢复密钥。本扩展没有发布者代管密钥或密码找回服务。本地密码加密不代表硬件绑定保护。扩展禁止在隐私窗口运行，尚未实现 Firefox 容器隔离。包的最低目标为 Chrome/Edge 120 和桌面 Firefox 140；商店审核及公开转账可用性须在发布前另行确认。
