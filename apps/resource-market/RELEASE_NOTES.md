# Release notes — 0.3.0 candidate

This unreleased local candidate adds a durable infrastructure market domain: provider verification, offers and matching, sealed reverse and split batch procurement auctions, quote-to-receipt state separation, expiring Ed25519 worker keys and signed metering, reconciliation, provider failure/retry, capped bond penalties and independent appeal. Auction clearing enforces immutable commitments, deadlines, self-dealing rejection, deterministic tie-breaking and honest insufficient-fill failure; output remains an expiring quote, never a reservation or settlement. Provider maintenance, capacity updates, guarded exit/migration, actor-scoped export, independent erasure fulfillment and a versioned transient-record retention sweep are also included. Erasure is blocked by live obligations and pseudonymizes identity without deleting economic, dispute, receipt or audit integrity. Settlement references are normalized, blank authorities fail closed and a transaction hash cannot be consumed by multiple receipts. Signed usage now supports bounded multi-segment workloads: every segment must begin after evidenced service start, intervals cannot overlap, cumulative quantity cannot exceed ordered units and cumulative protocol-fee allocation preserves exact quote reconciliation. Capacity reservations are now bound to the exact accepted offer, so an exhausted offer cannot borrow capacity from another offer by the same provider; settlement and evidenced failure release both offer and provider ledgers atomically. Fixed-price and auction provider self-dealing fail closed with a stable error code. Schema 6 derives the new reservation ledger from active order lineage during migration and rejects semantic ledger mismatch on restart. Quote, auction, metering, settlement and dispute calculations now use checked non-negative signed-64-bit arithmetic; overflow fails before quote creation, auction clearing, meter acceptance, reservation release, receipt creation or dispute decision. Authenticated `/api/market/*` routes return stable correlated error codes, including `RESOURCE_AMOUNT_OUT_OF_RANGE`. The frozen `resource-market-integration-v1` contract, dependency acceptance, handoff and cross-product negative vectors are enforced by automated tests. The local smoke harness builds and owns the exact temporary server process so cleanup leaves no stale listener. Provider/Buyer Web workspaces, request IDs, structured logs, process metrics and a reproducible local capacity probe are included.

This candidate is not centrally integrated, staged, public, hosted, production-signed or store-released. It has no public transaction receipt. A fresh Android debug APK was installed and cold-started on an Android 16 emulator; this does not prove production signing, native feature parity, canonical callback completion or public authority access.
