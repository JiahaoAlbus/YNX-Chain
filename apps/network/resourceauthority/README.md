# Original resource Source ownership

The helper now calls the original Auth Go→19 fixed C ABI constructor once at
normal service startup. A nonnull partial is retained before reading its error.
Retire/Join/Close use that same owner until physical completion; first cause is
separate, and a timeout never reacquires Source or a once claim. Live status
checks only Current. It reads no protected originals, creates no nonce, signs
nothing and dispatches no worker. Normal shutdown retains pending physical
drain rather than silently treating timeout as completion.

The private Auth Go/header intake is pinned in
`../internal/authresourcesource/SUPPLIER.json`. Darwin QA can link the supplied
C/Objective-C++ archive and static crypto with `--auth-source-handoff` and
`--auth-source-handoff-sha256` on `qa/build.mjs`. The fixed archive and all supplier
source pins are checked, the 19 guarded ABI definitions audited, and both static
libraries captured in private build space. It never links another Go runtime.
Default builds without that link and unsupported platforms return NOT_SUPPLIED.
No runtime argument, task payload, HTTP request or environment selector chooses
a Source, provider, program or Root row.

The kernel status DTO and existing strict browser projection show actual
linked/not-admitted/current/draining state without granting authority. OS counter
fields are accepted as exact decimal strings; previously their presence caused
the old strict projection to discard the entire resource submodel. The supplied
desktop/mobile light/dark layouts retain their structure; the resource list adds
one localized authorization-source row in all twelve languages.

Current actual release tables remain empty. Production Runner stays NewDisabled,
and its original sandbox journal/payload/signature bytes are unchanged. Canonical
original Work/Consent and the Native Claim.CurrentNoIO must still be composed
with P09's original authoritative nonce/UNKNOWN Store transaction before any
production execution path exists. Native O_EXCL is only an additional fence.
Sole SDK's normal Network dispatch, protected Native pending approval and typed
signer (prepare82/produce83), actual Root/release/Go image registrations and
platform containment remain independent requirements. This module enables none
of them by the presence of a C archive or a successful local test.
