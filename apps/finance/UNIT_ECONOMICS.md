# Finance unit economics

## Current evidence

YNX Finance is a non-custodial, read-only portfolio and planning product. The
current local candidate has no paid production users, no production provider
invoice, no production traffic baseline, and no accepted service revenue. Any
numeric per-user cost or gross-margin claim would therefore be invented.

| Cost or revenue | Current state | Required source before use |
|---|---|---|
| Finance service compute/storage | unavailable | deployed billing and usage export |
| Explorer reads | unavailable | Explorer owner rate/cost contract |
| Pay receipt reads | unavailable | Pay owner rate/cost contract |
| Exchange/DEX/Quant/Economics reads | unavailable | accepted owner contracts |
| AI explanation | unavailable | provider/model/token invoice |
| Support and abuse handling | unavailable | privacy-reviewed support telemetry |
| Subscription or service revenue | none accepted | founder-approved price and billing evidence |

## Measurement model

For a measured period:

`cost per active user = (compute + storage + network + provider + AI + support) / active users`

`gross margin candidate = accepted service revenue - attributable service costs`

Burn, treasury allocation, staking rewards, asset appreciation, user realized or
unrealized PnL, and provider pass-through costs are not Finance revenue. No APY,
fiat value, market cap, guaranteed return, or hidden spread may be inferred.

## Scale/kill gate

Scale only after at least one complete billing period provides source-bound
active users, task completion, retention, support load, abuse rate, provider
cost, infrastructure cost, and accepted revenue. Kill or redesign if required
owner sources remain unavailable, user value cannot be measured without
over-collection, or attributable cost cannot be sustainably covered.
