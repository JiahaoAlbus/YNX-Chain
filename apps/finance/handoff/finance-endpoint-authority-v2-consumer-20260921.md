The server verifies the signed root/manifest before returning them and includes its durable checkpoint and trusted-time anchor. The browser uses that server checkpoint as its recovery floor, so a complete IndexedDB plus localStorage clear cannot reset progression to the trust-root anchor. It still uses one IndexedDB read-write transaction for CAS, a marker for partial loss detection, a monotonic trusted clock, cross-tab invalidation and re-verification at begin, restore/callback, proof and order-persistence boundaries.

Its lock is atomically linked from a fully written owner record.
