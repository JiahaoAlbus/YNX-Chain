# Third-party notices and standards

The application dependency inventory is pinned by `package-lock.json`; license review and known limitations are in `DEPENDENCY_REVIEW.md`. Key direct dependencies include Expo/React Native/React (MIT), Noble cryptography libraries (MIT), Lucide icons (ISC), and React Native SVG/Safe Area/QR packages under their published open-source licenses. The exact transitive license text must be generated and reviewed from the release lock before public binary distribution.

Protocol references are ERC-4337/7769/7562 (Ethereum Improvement Proposal repository terms), W3C WebAuthn Level 3, Verifiable Credentials Data Model 2.0 and Bitstring Status List 1.0 (W3C document license), OpenID Connect Core (OpenID Foundation), and IETF RFC 9449/9700. References define interoperability and security boundaries; no specification name implies certification or endorsement.

Reown Swift 2.3.1 is pinned from `https://github.com/reown-com/reown-swift.git` for the native Apple WalletConnect v2 Sign, Pair and Networking runtime. WalletKit Items are governed by the WalletConnect Community License Agreement released 20 August 2025, not by an open-source license. The required notice is: “Portions © 2025 Reown, Inc. All Rights Reserved”. The full agreement is bundled in `REOWN_WALLETKIT_LICENSE.md` and must remain in every distributed application notice/about surface. Runtime use must connect to Reown gateway infrastructure and is subject to the license's RPC/MAU commercial thresholds, Terms of Service, Acceptable Use Policy, branding, export-control and future-version obligations. Legal/release-owner approval remains required before distribution.

The macOS build applies the source-visible compatibility operation in `macos/scripts/prepare-reown-macos.sh`, strictly after verifying Reown Swift commit `968a82d440e51c4de18857928b60a03d36af7a2a` and original source blob `34b299ee3b325f26536980d272e0e7f906fe2869`. The modified source carries a prominent YNX Wallet notice; the operation adds only the Foundation import required for the upstream-declared macOS target.

MetaMask, Rabby, Phantom and Apple Wallet are comparative product references only; their trademarks and assets are not included. YNX Wallet metadata, icon, bundle identities and `isYNXWallet` marker remain distinct and never set `isMetaMask`.

Smart Account build dependencies include eth-infinitism `@account-abstraction/contracts` 0.8.0 (MIT) and OpenZeppelin Contracts 5.6.1 (MIT). The official account-abstraction npm dependency graph also contains Uniswap v2/v3 packages under GPL-2.0-or-later, GPL-3.0-or-later and BUSL-1.1 declarations. No Uniswap contract is imported into the YNX Smart Account source, but those build dependencies and their exact license texts must remain in release notices and legal review.
