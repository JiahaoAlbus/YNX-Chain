`effect.Execute(ctx, func(txCtx context.Context) error { return originalProductTransaction(txCtx) })` owns the SAME authority gate while it rechecks exact captured epoch/source snapshot and enters the original local synchronous product commit. The product transaction must check original nonce, object/current role/member/window/cancel then commit nonce+effect together. This coordinator neither creates nor owns another nonce store. Callback must not run remote preflight; do it first and capture afterward. Callback carries a marked context for reentry rejection; a fresh/background context must not be used to bypass the contract. Effect lease retains the original Capture context; a later fresh Execute context cannot resurrect a cancelled/deadline-expired capture. Original and execution contexts are checked before and after the effect. Effect lease is one-shot once callback enters; local cancellation/error/panic cannot permit replay or automatic retry.

The internal epoch is only a coordinator invalidation counter; it is NEVER returned as PrivateGeneration or enrollment. No metadata is durably created by incrementing it. Successful original durable commit and source publication must finish under this gate; outside-gate mutations violate the integration and cannot be declared supported. `writer.Retire(ctx)` terminally invalidates the coordinator. Replace source only by constructing a new instance with new explicit captures; never migrate pending effect leases.

## Lock order and linearization

The unique order is coordinator authority gate -> original auth/member or product transaction lock. ALL original auth/member mutations and effect commits must participate in this same gate. Never enter coordinator while already holding a product/auth Store lock; never call a source callback that reacquires that Store. Source observation must be locally accessible without product lock, published by its original writer under the authority gate. No network, await, goroutine dispatch of the actual commit, remote cache/pubsub or recursive Store call is permitted while the gate is owned. Callbacks are synchronous and bounded; the component cannot forcibly kill a misbehaving Go callback.

If effect wins the gate, original revoke waits until that effect finishes. If revoke wins, epoch invalidation makes old captures fail before their callback. A writer uncertainty retires the whole instance. These are actual mutual-exclusion semantics of this mechanism, conditional on BOTH original writers and product commits truly participating. It does not serialize a remote Node writer that never acquired this gate. Existing Node auth writer and Go product topology currently lacks that ownership connection; the previously frozen authwriter extension plan remains required. A same-process original authority/effect integration or genuine atomic coordination is necessary for activation, not a pair of HTTP reads.

Post-effect source read/current/expiry/cancel rejects unexpected external changes. If callback was entered, errors return EffectStarted=true with EFFECT_OUTCOME_UNCONFIRMED; the original effect might have committed. Do not interpret that as rollback or retry. The original durable effect/outcome journal supplies recovery. Panic retires and rethrows after releasing the gate. This conservative API does not run cleanup, change original state or erase outcomes. Legitimate commands that themselves change captured membership/authority must be owned writer transactions with original authorization checks; ordinary Execute is not a membership enrollment API and will reject an uncoordinated changed snapshot.

## Boundary repair successor

Registration rejects nil interfaces and typed nil values for all reflect kinds accepting IsNil (Chan, Func, Interface, Map, Pointer, Slice). Non-nil implementations remain eligible only for the protected composition seam; this does not attest provenance. Mutate checks its exact transaction context after synchronous Current and before epoch invalidation/commit entry. Known cancellation or expired deadline returns CANCELLED without invoking commit, changing epoch or retiring an unentered writer. Cancellation after entry retains the existing uncertain-commit/retirement contract. This fence cannot eliminate cancellation concurrent with subsequent instructions or forcibly interrupt callbacks; original durable writer must check its operation context at its own commit decision. Same-instance participant exclusion remains the scope: remote Node authority and a missing actual original enrollment/membership producer are not supplied by this repair.
