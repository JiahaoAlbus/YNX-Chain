# Native Media product consumer

`media-session.mjs` directly consumes the frozen matching Native SDK carried under `apps/music/web/vendor/wallet-auth-5c5e8a23/`. It supplies product-selected registered scopes for Video, Creator and Music, uses the original published Video/Creator `/video/api` and native Music `web4.ynxweb4.com/music` service prefixes while signing the original backend `/v1/...` or `/api/...` paths/body-proof headers, and requires original same-account service readback before private JSON business calls. It does not create keys, enroll accounts, bind old keys to a new authority, migrate state or export private material.

The caller must supply the actual platform runtime defined by the matching `product-session-native.d.ts`: protected readContext, random, signer, Wallet launch and atomic durable storage/revocation ports; actual Wallet/scheme detection; and a Fetch/Response/Streams bridge supporting the standard wire objects. Account, deviceId, compressed public key, generation and security level are read from this trusted native runtime. Android/iOS/macOS are explicit targets; Music Linux/Windows remain unregistered. A hardware/OS security label is valid only when the platform implementation proves it.

Use `connect()` for the original SDK-controlled Wallet request and OS launch; launch receipts are never approval. Pass the complete original callback to `handleReturn()`. Call `restore()` for cold return and after network recovery: it revalidates authority and reads the original `/v1/account` or `/api/me` before exposing `current.businessVerified`. `json(path, options)` signs the exact immutable original request bytes and checks the same native context, session, consumer revision, cancellation and original response location at every boundary. The response JSON is bounded and has the original 30-second consumer deadline. Wrong service account rejects activation. `disconnect()` retains the SDK's durable revoke intent until confirmed; `close()` fences this consumer without deleting any protected identity.

The existing Android and Apple screens, device aliases, Keychain items, content and drafts remain intact. This module is an actual product consumer ready for the owner's protected OS runtime integration; it is not yet wired into those shipped UI entrypoints. Do not replace those products with a QA window or Web wrapper, and do not describe this source as an installed native release.

`media-native-authority-check.mjs` runs the actual Native SDK with disposable software QA ports against the actual matching Node authority and original Go business HTTP/store. The registered Android/macOS cases cover Video, Creator and Music, wrong callback state, same-account readback and original write, cold recovery, wrong account veto, in-flight consumer replacement and remote revoke. These tests do not prove AndroidKeyStore/Keychain/secure enclave behavior, current Central actor, real Wallet approval or public installation.

Web's separately delivered 641 combined authority contract requires original complete private Session plus original sealed BrowserSSO binding in one decision. No Native grant, standard EVM connection or unregistered Music identity is substituted for that contract. Operator registration, private backend keys, Host and current actor/CSRF configuration remain A-owned.
